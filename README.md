## <아이디어 구상하기>
TO-DO 캘린더 + 강의 시간표 충돌 검사기
(LMS에서 영감을 받음)
월~금일의 일정을 등록 및 삭제, 그리고 조회를 가능하게 함(원하는 날짜의 일정 등록을 통해 편의성 추구)

## <알고리즘 구현하기>
[일정 추가, 일정 확인, 요일 선택, 일정 삭제, 프로그램 종료 버튼 띄우기]
  {일정 추가 선택}
  [새 할 일 추가, 기존 할 일 수정, 돌아가기 버튼 띄우기]
    {새 할 일 추가 선택}
      할 일 입력
        [오늘만, 매주 요일 반복, 취소 버튼 띄우기]
          {오늘만 선택}
            오늘만 할 일 띄우기
          {매주 요일 반복 선택}
            매주 해당 요일 마다 할 일 띄우기
          {취소 선택}
            할 일 입력 취소
    {기존 할 일 수정 선택}
      수정 할 내용 입력
    {돌아가기 버튼 선택}
      맨 처음 화면으로 돌아가기
  {일정 확인 선택}
   전체 일정 띄우기
  {요일 선택}
  [월, 화, 수, 목, 금, 토, 일, 돌아가기 버튼 띄우기]
    {요일 선택}
      해당 요일 일정 띄우기
  {일정 삭제 선택}
  [오늘 날짜, 날짜 직접 입력, 돌아가기 버튼 띄우기]
    {오늘 날짜 선택}
    [일정 초기화, 취소 버튼 띄우기]
      {일정 초기화 선택}
        오늘 일정 삭제
      {취소 선택}
        일정 삭제 취소
    {날짜 직접 입력}
      날찌 입력 띄우기
        {날짜 입력}
          해당 날짜 일정 띄우기
          [일정 초기화, 취소 버튼 띄우기]
            {일정 초기화 선택}
              해당 날짜 일정 삭제
            {취소 선택}
              해당 날짜 일정 삭제 취소
    {돌아가기 선택}
      맨 처음 화면으로 돌아가기
  {프로그램 종료 버튼 선택}
